# 钻石切工设计与火彩预览系统

浏览器端钻石切工设计工具:参数化切工建模 + WebGPU 实时光线追踪渲染 + 光学分析。
TypeScript + WebGPU(WGSL),无框架,零运行时依赖。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建(dist/)
npm run preview    # 预览生产构建
npm test           # 物理/几何/着色器单元测试(35 项)
```

需要支持 WebGPU 的浏览器(Chrome / Edge 113+)。

## 功能

| 页面 | 功能 |
| --- | --- |
| 款式库 | 新建/复制/删除,localStorage 持久化,JSON 导出导入 |
| 切工编辑 | 圆形明亮式/公主方/椭圆参数化生成;台面比、冠角、亭角、腰棱、星刻面、下腰面、底尖、人字层、长宽比可调;非凸参数实时报错 |
| 渲染预览 | WebGPU 全屏光线追踪;三种环境光(珠宝柜台灯/自然光/点光源);自动转台;对比模式双石并排;1080p 截图导出 |
| 光学分析 | 亮度/火彩/闪烁评分,漏光率,光返回图,漏光刻面归属图(红=漏光),Markdown 参数报告导出 |
| 设置 | 渲染分辨率/自适应降档、内反射次数、光谱采样;GPU vs CPU 单光线物理核对 |

## 物理模型

- **折射**:斯涅尔定律,逐波长计算(色散)。钻石折射率用柯西公式,
  由实测夫琅禾费谱线拟合(n_F=2.4354@486.1nm,n_C=2.4103@656.3nm,n_D≈2.4175)。
- **全内反射**:临界角 ≈24.44°(钠黄光),内部反弹次数可调(默认 10)。
- **菲涅尔**:非偏振精确解(非 Schlick 近似),入射/出射界面能量加权。
- **色散**:红(656.3nm)/绿(546.1nm)/蓝(486.1nm)三波长独立追踪,合成火彩。
- **几何**:凸多面体板条求交;生成器输出经凸性校验(非凸参数组合会被拒绝)。

## 精度验证(用户核心诉求)

- CPU 参考实现为 float64,单元测试用独立公式核对斯涅尔定律,误差 < 0.01°
  (`tests/optics.test.ts`,平行平板/直角棱镜/横向位移手算对照 `tests/raytrace.test.ts`)。
- WGSL 着色器与 CPU 实现一一对应;**设置页「运行核对」**用 GPU 计算着色器
  追踪 12 条代表性光线与 CPU 对照,实测最大出射角误差 **5.96e-5°**(fp32)。
- `scripts/verify-e2e.mjs` / `scripts/verify-full.mjs`:真实浏览器端到端验证
  (GPU 核对、FPS、全部页面功能),需本机装有 playwright chromium。

## 性能

1080p 实时转动 60fps(实测,RTX 3060,75% 内部分辨率)。
自适应分辨率在帧率不足时自动降档保 30fps,可在设置关闭。

## 代码结构

```
src/
  math/       向量/矩阵
  physics/    斯涅尔折射、菲涅尔、柯西色散、CPU 参考光线追踪器
  geometry/   三种切工参数化生成器 + 凸性校验
  render/     WebGPU 渲染器、WGSL 着色器、环境光、漏光网格渲染
  analysis/   亮度/火彩/闪烁/漏光分析(CPU 追踪)
  state/      款式库 localStorage 存储
  ui/         五个页面 + 预览面板组件
tests/        35 项单元测试(物理精度、几何凸性、WGSL 静态校验、分析合理性)
scripts/      端到端验证脚本(playwright-core)
```
