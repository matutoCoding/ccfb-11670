# 钻石切工光学评估系统

浏览器内的钻石切工光学评估工具:下盘之前先把比例定准。
TypeScript + WebGPU,全部光学计算在 CPU 上以双精度完成,无随机采样。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查 + 生产构建
npm test         # 物理内核验证(斯涅尔定律 / ASET 连续性等 13 项)
```

浏览器要求:转台 3D 视图需要 WebGPU(Chrome/Edge 113+);无 WebGPU 时自动退回 2D 线框,其余功能不受影响。

## 页面

| 页面 | 功能 |
|---|---|
| 比例方案 | 圆钻/公主方/椭圆参数化(台面比、冠角、亭角、腰厚、底尖),亭角步长 0.05°,预设模板,A/B 两套方案 |
| 刻面编辑 | 单个刻面的倾角/方位磨偏,腰部波浪(振幅/瓣数/相位) |
| 光学观测 | 单光线逐刻面追迹(入射角/折射角表)、ASET 镜、IdealScope、八心八箭对称度、转台闪烁(三种光源) |
| 切工评级 | 亮度/火彩/闪烁打分,A/B 并排 ASET + 差异高亮,生成客户确认报告(可打印) |
| 设置 | 光源模型、ASET 分区角度、评分采样密度 |

## 物理口径

- 折射率:Sellmeier 方程随波长变化,n_D(589.3nm)≈2.4175,临界角 ≈24.44°
- 每次折射/反射按斯涅尔定律双精度计算,单条光线每次折射角与手算误差 < 0.01°(有测试锁定)
- 全内反射、菲涅尔能量损失逐次计入
- ASET 分区:仰角 ≥75° 蓝(头部遮挡),45–75° 红(直射光),<45° 绿(环境光),亭部逸出为黑色漏光
- 评分以 Tolkowsky 理想切工同光源实测值为基准 1.0:优 EX ≥0.90,良 VG ≥0.75,中 G ≥0.55,差 F <0.55
- 全部确定性采样:亭角 40.6°→41.2° 微调时 ASET 漏光面积连续变化(有测试锁定)

## 代码结构

```
src/core/      双精度向量、斯涅尔折射、Sellmeier 色散、菲涅尔
src/geometry/  参数化刻面生成(圆钻 73 刻面 / 公主方 / 椭圆)+ 磨偏缺陷
src/optics/    追迹器、ASET/IdealScope、八心八箭、评分、光源模型
src/render/    WebGPU 转台渲染(含 2D 兜底)
src/ui/        五个页面 + 报告
test/          物理验证测试
```
