# 钻石切工设计与火彩预览系统

浏览器内的钻石切工设计、真实光学渲染与光学分析工具。TypeScript + WebGPU，无需后端。

## 功能

| 页面 | 功能 |
|------|------|
| **款式库** | 新建 / 复制 / 删除 / 重命名款式，localStorage 持久化，JSON 导出 / 导入 |
| **切工编辑** | 圆形明亮式、公主方、椭圆形参数化生成；台面比、冠角、亭角、腰棱、星刻面、下腰刻面、长宽比可调；实时预览 + 全深比/冠高比/亭深比测量 |
| **渲染预览** | WebGPU 光谱光线追踪；三种环境光（珠宝柜台灯 / 自然光 / 点光源）；拖拽旋转、滚轮缩放、自动转台；对比模式两款并排；2× 超采样截图 PNG |
| **光学分析** | 出光图（哪些刻面回光）、漏光图、火彩图；亮度 / 火彩 / 闪烁三项评分；刻面漏光排行；导出 HTML 参数报告 |
| **设置** | 波长数 / 反弹次数 / 分辨率 / 柯西色散系数；内置物理自检 |

## 物理模型

- **光谱光线追踪**：每个波长独立走完整路径（CPU 参考实现 `src/optics/raytrace.ts`，GPU 着色器 `src/gpu/shader.ts` 与之镜像）
- **斯涅尔折射** + **全内反射（TIR）** + **完整菲涅尔方程**（非 Schlick 近似）
- **柯西色散**：n(λ) = A + B/λ²，默认 A=2.3798、B=0.01315 µm²（拟合钻石 n_F=2.4354、n_C=2.4103，n_d≈2.417，色散 0.044）
- 宝石建模为**凸多面体半空间交集**，slab 法求交，解析精确（非三角形求交近似）

### 物理验证（验收标准：单条光线 vs 手算斯涅尔定律误差 < 0.01°）

`npm test` 共 23 项测试，实测最大折射角误差 **~1.7e-12°**：

- 多角度 × 多折射率组合 vs 解析解 `θt = asin(n₁/n₂·sinθi)`
- 临界角（钻石 24.44°）两侧 TIR 判定
- 平行平板出射平行性、棱镜 TIR 偏向、能量守恒（反射+透射+困住 = 1）
- 色散：蓝光偏折 > 红光
- 理想切工（亭角 40.8°）中心光返回 vs 过浅切工（36°）漏光对比
- 三种切工 × 多组参数的凸包合法性

设置页内置同样的自检，可在浏览器里现场演示。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm test           # 物理与几何单元测试
npm run build      # 生产构建（含类型检查）
npm run smoke      # 端到端冒烟测试（需 dev 服务器运行在 5231 端口）
```

**要求**：支持 WebGPU 的浏览器（Chrome / Edge 113+）。

## 性能

1080p 转动 ≥ 30fps 的设计保障：

- 默认 0.75 内部分辨率 + **自适应分辨率**（帧率 < 28 自动降档、> 55 升档，可在设置关闭）
- 波长数 1 / 3 / 5 可调（默认 3），反弹次数可调（默认 8，通量 < 1e-3 提前终止）
- 凸多面体解析求交：每像素每波长约 73 平面 × (1 次进入 + ≤8 次反弹)，无 BVH 遍历开销
- 预览页 HUD 实时显示 FPS 与当前渲染分辨率
